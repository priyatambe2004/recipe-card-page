 # Recipe Card Page

A responsive recipe card page for **Kanda Poha**, built with **HTML5 and CSS3** only.
This project is part of my Web Development Internship at **Veda Technology** (Task 11).

🔗 **Live Demo:**  https://priyatambe2004.github.io/recipe-card-page/

## 📌 About the Project

A single recipe card page that shows an image, an ingredients list, and numbered preparation steps. The layout is two columns on desktop and one column on mobile.

## 🎯 Objective

To practice semantic HTML structure and CSS card styling.

## ✨ Features

- Styled recipe card with an image, ingredients, and steps
- Semantic HTML: `article`, `header`, `figure` with `figcaption`, `section`, `aside`, and `footer`
- Unordered list (`ul`) for ingredients and ordered list (`ol`) for steps
- Ingredient checkboxes that strike through when ticked (CSS only, no JavaScript)
- Numbered step circles built with CSS counters
- Recipe details: prep time, cook time, servings, and difficulty
- Chef's tip box
- Responsive layout with CSS Grid
- Consistent spacing and colours using CSS variables
- Print-friendly styles
- Accessible markup: image `alt` text, labelled sections, and keyboard-friendly checkboxes

## 🛠️ Technologies Used

- HTML5
- CSS3 (Grid, Flexbox, CSS variables, counters, media queries)

## 📚 What I Learned

- Using semantic elements to give a page meaning
- Why steps use an ordered list instead of a paragraph
- Using `figure` and `figcaption` for images
- The CSS box model and `box-sizing: border-box`
- Building a card container with consistent spacing
- Making a layout responsive with CSS Grid and media queries
- Styling form checkboxes with CSS only

## 🚀 How to Run

1. Download or clone this repository:
   ```
   git clone https://github.com/your-username/recipe-card.git
   ```
2. Open the folder.
3. Double-click `index.html` to open it in your browser.

## 🖼️ Image Note

The recipe image (`recipe.svg`) is an illustration created for this project. To use your own photo, add it to the folder and update the `src` and `alt` text in the `<img>` tag in `index.html`.
